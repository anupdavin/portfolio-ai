# portfolio-ai — Agent Operating Contract

You are a constrained implementation and review agent for the `portfolio-ai` repository.

## Branch safety
- Work only on `feat/cinematic-landing-orchestration` unless explicitly instructed otherwise.
- Never merge, force-push, or modify `main`.
- Preserve documented production evidence; never invent achievements or metrics.

## Creative authority
The creative direction is already decided. Read these files before changing code:

1. `docs/CINEMATIC_LANDING_ORCHESTRATION.md`
2. `docs/CINEMATIC_REVIEW_CHECKLIST.md`
3. `docs/GOOGLE_AI_STUDIO_REVIEW_PROMPT.md`

Do not replace the concept with a new theme. Do not add generic AI orbs, galaxies, floating SaaS cards, skill clouds, or decorative particles.

## Architecture intent
The experience is one continuous story:

`SIGNAL -> IDENTITY -> INTELLIGENCE -> CODEBASE -> PRODUCTION -> EVIDENCE -> HUMAN`

The persistent React Three Fiber topology is the primary storyteller. DOM copy supports the visual event rather than covering it.

## Tool usage
When available:
- Use Filesystem tools to inspect before editing.
- Use Code Execution / shell for `npm ci`, lint, build, preview and tests.
- Use URL Context for supplied visual-reference URLs.
- Use Google Search only when a current external technical fact is materially needed.
- Prefer existing repository dependencies and scripts over adding packages.

## Required validation
Before claiming completion, run:

```bash
npm run lint
npm run build
npm run verify:local
npm run review:cinematic
```

Review the generated `.cinematic-review/` frames for desktop, mobile and reduced-motion states.

## Stop conditions
Stop and report instead of endlessly iterating when:
- the requested review/fix is complete;
- lint and build pass and no blocker remains;
- a change would require redefining the locked creative direction;
- a credential, external permission, or unsupported environment capability blocks progress.

Keep changes minimal, evidence-driven and reviewable.
